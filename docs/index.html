QR Code Scanner 是一款簡潔的 Android 掃描器，支援文字、網址、簡訊、電話、Email 與 Wi-Fi 內容。掃描歷史留在你的裝置上，常用紀錄也能加入最愛。

Made for everyday scans

該有的功能，保持清楚簡單

從辨識到下一步，每個動作都由你決定。

辨識 QR Code 與 Aztec

✓ 使用相機快速掃描，支援常見的 QR Code 與 Aztec 條碼。

✓ 純文字可自動複製，並可選擇震動提示。

掃描後交給正確的工具

✓ 網址交給瀏覽器、電話交給撥號程式、Email 交給郵件 App。

✓ Wi-Fi 使用 Android 系統的加入網路流程，不靜默連線。

保留完整歷史

每筆結果可保存、複製、刪除，也能標記為最愛。

網址標題輔助

在背景嘗試讀取網址標題；即使失敗，原始網址仍會保存。

明亮與深色外觀

依你的使用習慣選擇舒適的畫面外觀。

Private by design

你的掃描內容，由你掌握。

App 不會把掃描歷史上傳至維護者的伺服器；完整範圍與例外請查看隱私權政策。
